# 🔔 Telegram Reminder Bot (`bot_notify`)

Современный, производительный и удобный Telegram-бот для создания напоминаний на русском языке с поддержкой естественной речи, часовых поясов, тихих часов и повторяющихся задач.

---

## 🌟 Что умеет бот

1. **Распознавание естественного языка (NLP)**:
   - *«завтра в 15:00 позвонить маме»*
   - *«через 30 минут выключить духовку»*
   - *«каждый день в 20:00 принимать витамины»*
   - *«по будням в 8:30 вставать»*
   - *«каждую субботу в 12:00 уборка»*
   - *«каждое 1 число месяца в 10:00 оплатить подписки»*
2. **Быстрый UX & Inline-интерфейс**:
   - Главное меню с inline-кнопками: ➕ Создать, 📋 Мои напоминания, 📅 Сегодня, 🔁 Повторяющиеся, ⚙️ Настройки, ❓ Помощь.
   - Карточки подтверждения создания, кнопки откладывания (+5м, +15м, +30м, +1ч, +3ч, Завтра, Своё время) и управления (Выполнено, Изменить, Перенести, Удалить).
3. **Умное уточнение**:
   - При написании *«напомни купить билеты»* без указания времени бот не создаст некорректную задачу, а предложит удобные быстры кнопки выбора времени.
4. **Контекстные действия**:
   - Поддержка фразы *«перенеси на завтра»* для сдвига последнего напоминания.
5. **Часовые пояса и тихие часы**:
   - Указание часового пояса пользователя (автоматически или вручную).
   - Настройка «тихих часов» (например, `23:00–07:00`) с выбором типа доставки (без звука или сдвиг на утро).
6. **Надёжный Scheduler & Устойчивость к перезапускам**:
   - Восстановление и автоматическая рассылка всех активных задач из SQLite / PostgreSQL при рестарте сервера.
   - Защита от дублирующих уведомлений.

## 🚀 Быстрый запуск

### 1. Создание Telegram-бота через BotFather

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте инструкциям.
3. Скопируйте полученный **API Token** (например, `123456789:ABCdefGHIjklMNOpqrsTUVwxyZ`).

### 2. Настройка окружения (`.env`)

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```env
BOT_TOKEN=ваш_telegram_bot_token
DATABASE_URL=sqlite+aiosqlite:///./bot_notify.db
DEFAULT_TIMEZONE=Europe/Moscow
LOG_LEVEL=INFO
```

### 3. Локальный запуск (Python)

1. Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv venv
# Linux / macOS:
source venv/bin/activate
# Windows:
venv\Scripts\activate

pip install -r requirements.txt
```

2. Запустите тесты, чтобы убедиться в корректности:

```bash
pytest
```

3. Запустите бота:

```bash
python -m app.main
```

## 🤖 Настройка AI Fallback (опционально)

По умолчанию бот использует детерминированный гибридный парсер на русском языке, работающий моментально и офлайн.

Если вы хотите подключить обработку сложных и двусмысленных фраз через LLM:
1. Получите ключ Gemini API или OpenAI API.
2. Укажите в `.env`:
   ```env
   AI_API_KEY=your_api_key_here
   AI_PROVIDER=gemini  # или openai
   ```

## 🧪 Тестирование

Проект содержит 100% покрытие ключевых узлов:

```bash
pytest -v
```

Тесты проверяют:
- Парсинг 20+ вариантов фраз на русском языке.
- Относительные даты и интервалы.
- Повторяющиеся правила (`DAILY`, `WEEKLY`, `MONTHLY`, `INTERVAL`).
- Перевод в UTC и конвертацию часовых поясов.
- Выполнение, откладывание (snooze) и удаление задач.
- Устойчивость фонового шедулера к дубликатам уведомлений.

## 🔧 Troubleshooting

- **Бот не отвечает на сообщения**: Убедитесь, что `BOT_TOKEN` указан корректно и не запущен другой экземпляр бота с тем же токеном.
- **Время напоминания сдвинуто**: Проверьте текущий часовой пояс в `/settings`.
- **Ошибка базы данных при старте**: Проверьте права на запись в текущей директории для SQLite файла `bot_notify.db`.
